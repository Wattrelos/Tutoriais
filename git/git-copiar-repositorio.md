# Copiar um repositório do GitHub

# Requisitos:
 **Git** Git instalado na máquina ou o plugin do VS Code. |
 **IDE** Alguma IDE instalada, como o [Antigravity IDE] ou [Visual Studio Code (VS Code)] |

## Se você ainda não tem uma IDE instalada, pode utilizar um dos tutoriais abaixo:

* [Instalar Antigravity IDE](/tutoriais/dev-tools/antigravity-ide.md)
* [Instalar Visual Studio Code (VS Code)](https://code.visualstudio.com/download)


Se ainda não tem o [Git](https://git-scm.com/downloads) instalado na máquina, você pode instalá-lo clicando aqui: [Instalar Git](https://git-scm.com/downloads)


## No [Visual Studio Code (VS Code)](https://code.visualstudio.com/), você pode fazer isso de duas maneiras principais:
## Opção 1: Pelo Terminal Integrado (Mais comum)

   1. Abra o VS Code.
   2. Abra o terminal integrado acessando o menu superior: Terminal > Novo Terminal (ou use o atalho Ctrl + ').
   3. Navegue até a pasta onde deseja salvar o projeto (ex: cd NomeDaPasta).
   4. Cole e execute o seu comando:
   
   git clone https://github.com/Wattrelos/FATEC-FV_Teste_Software_aula-003
   
   5. Após o término, digite code FATEC-FV_Teste_Software_aula-003 para abrir a pasta do projeto diretamente no VS Code. [3, 4] 

## Opção 2: Pela Interface Gráfica do VS Code (Sem digitar comandos)
Se preferir não usar o terminal, o próprio VS Code possui uma ferramenta nativa de clonagem: [5] 

   1. Use o atalho Ctrl + Shift + P (no Windows/Linux) ou Cmd + Shift + P (no Mac) para abrir a Paleta de Comandos.
   2. Digite Git: Clone e selecione essa opção.
   3. Cole a URL do repositório (https://github.com/Wattrelos/FATEC-FV_Teste_Software_aula-003) e aperte Enter.
   4. Uma janela do seu sistema operacional vai abrir para você escolher em qual pasta deseja salvar o repositório.
   5. Assim que o download terminar, o VS Code exibirá uma notificação no canto inferior direito perguntando se você deseja abrir o repositório clonado. Basta clicar em Abrir. [3, 4, 6, 7]
