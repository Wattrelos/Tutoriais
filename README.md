# Tutoriais
Este repositório visa reunir vários tutoriais de consulta rápida visando o desenvolvimento de software, com foco em Python, Java, Android, Banco de Dados e Web.

Isto é útil, por exemplo, quando eu comprei um laptop novo e precisei instalar tudo do zero. Daí eu criei este repositório para guardar os tutoriais que eu criei. Em pouco tempo eu já tinha um ambiente de deselvolvimento completo e funcional, com todas as ferramentas que eu precisava para desenvolver software. E o melhor de tudo, eu podia reinstalar tudo em minutos caso precisasse.
